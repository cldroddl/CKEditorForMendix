# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Mendix **Dojo/Dijit** widget package (generated by `generator-mendix`, ~2016 era) containing two widgets:
- `CKEditorForMendix` — the WYSIWYG editor
- `CKEditorViewerForMendix` — read-only viewer that rewrites links to trigger microflows

Only two hand-written source files matter: `src/CKEditorForMendix/widget/CKEditorForMendix.js` and `CKEditorViewerForMendix.js`. Everything under `src/CKEditorForMendix/widget/lib/` is **vendored** (CKEditor 4.10.0, jQuery, plugins) — changing editor behavior means editing those vendored files (e.g. `lib/config.js`, `lib/build-config.js`) or the custom `mendixlink` plugin.

## Commands

Scripts run Gulp 3 (`node ./node_modules/gulp/bin/gulp <task>`):

| Command | Effect |
|---|---|
| `npm run dev` | Watch `src/**/*`, rebuild `.mpk`, copy JS into the test project deployment folder |
| `npm run build` | Zip `src/**/*` into `CKEditorForMendix.mpk` → `test/widgets/` and `dist/` (runs `clean` first) |
| `npm run version -- -n <version>` | Bump version in `src/package.xml` and `package.json` |
| `npm run icon [--file ./icon.png]` | Print base64 `<icon>` string for the widget `.xml` |
| `npm run lint` | Run jshint (`.jshintrc`) over the two hand-written widget JS files |

There is **no test runner and no CI**. `test/` is a Mendix 7 test *project*, not a unit-test suite — manual testing only.

## Code style (widget JS)

ES5 only — `"use strict"`, AMD `define([...])`, no TypeScript/Babel/JSX. Enforced conventions (from `.jshintrc`):
- Double quotes, strict equality (`===`), 4-space indentation
- jQuery is loaded with `.noConflict(true)` and used as a widget-local `$`

## Repo etiquette

- Branch off `master` and open a PR — do not commit to `master` directly.
- **Do not stage rebuilt `.mpk` files.** `dist/CKEditorForMendix.mpk`, `test/widgets/*.mpk`, and root `Test.mpk` are committed artifacts but are only updated deliberately on release, not in feature commits.
- `origin` is the fork `github.com/cldroddl/CKEditorForMendix`.

## Gotchas

- `npm install` pulls a GitHub tarball dependency (`widgetbuilder-gulp-helper`) — needs network access.
- `settings/ckeditorformendix.mws` and `package.json` `paths.testProjectFolder` contain stale values from a previous author's machine — ignore them.
